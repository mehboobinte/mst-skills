# Driving Google Flow — interface mechanics

Read this when the user needs to know *how* to operate Flow, not just what to type.
Flow lives at labs.google/fx/tools/flow and needs a Google AI Pro or Ultra plan
(Pro includes a monthly generation allowance; Ultra gives the highest limits and
earliest model access). Access and limits change often — if the user asks about
current pricing or quota, check Google's page rather than answering from memory.

## The four generation modes

| Mode | What it takes | Use it for |
|---|---|---|
| **Text to Video** | prompt only | establishing shots, anything with no existing asset |
| **Frames to Video** | start frame (+ optional end frame) + prompt | joining clips; controlling exactly where a shot begins/ends |
| **Ingredients to Video** | up to 3 reference images + prompt | keeping a person, product, truck or style consistent |
| **Extend** | an existing clip + prompt | continuing past 8 seconds |

## Ingredients — the consistency tool

An ingredient is a locked visual element: a character, an object, or a style reference.
Either upload a photo or generate one with the image model first.

- Max **3 per prompt**.
- For MST, the best ingredients are the user's **own godown, rack, pipe-stack and truck
  photos** — real photos beat any description.
- Generate a character ingredient once (e.g. the worker in blue hard hat and grey
  shalwar kameez), save it, and reuse it in every clip of the project. This solves the
  "his face changed" problem better than any prompt wording.
- A style ingredient (one frame you liked) keeps the grade consistent across a series.

## Building past 8 seconds

Two ways, in order of reliability:

1. **Frames to Video** — export the last frame of clip 1, feed it as the start frame of
   clip 2. The join is near-seamless. Best for a continuous action.
2. **Extend** in the scene builder — Flow continues the existing clip from its end.
   Faster, but drift is more likely; repeat the full description in the extend prompt.

Either way: **repeat the entire description each time.** Veo does not remember the
previous prompt. Referring to "the same man as before" without describing him again
produces a different man.

## Credit discipline

Generations cost quota, so:

- Iterate at **720p**, finalise at 1080p.
- Test a risky idea at **4 seconds** before committing to 8.
- Lock the shot list with the user *before* generating anything.
- Save every usable clip immediately — including near-misses, they make good B-roll.
- If two out of three attempts at a shot fail the same way, the prompt is wrong, not
  unlucky. Change one variable (camera move, or action, or light) and retry — not all
  three at once.

## Flow TV

Flow TV shows clips other people made **with their exact prompts visible**. When a shot
type keeps failing, find something similar there and copy the phrasing pattern. This is
the fastest way to learn what wording the model actually responds to.

## Export, then finish in an editor

Flow output is raw footage. What must happen afterwards, outside Flow:

1. **Trim and sequence** — Flow's scene builder can assemble, but a normal editor
   (CapCut, Premiere, even Canva) is easier for precise cuts.
2. **Urdu captions and titles** — typed properly, never generated.
3. **Brand name, phone number, website** — as an overlay or end card.
4. **Urdu voice-over** — record a real male voice if possible; a good TTS is acceptable.
   Duck the ambient audio under the voice, don't mute it entirely — the ambient sound is
   what makes it feel real.
5. **Music** — optional and usually unnecessary for a trade/industrial video. If used,
   keep it low and rhythmic, no vocals.
6. **Export twice** — 9:16 for WhatsApp status / Reels / Shorts, 16:9 for YouTube and
   the website. Frame the original generation so both crops survive: keep the subject
   centred, nothing important near the left/right edges.

## Quick pre-publish checklist

- [ ] Any visible text checked character by character (or removed)
- [ ] No Urdu script generated by the model anywhere in frame
- [ ] Same person/truck/light across all clips
- [ ] Pipes look like real steel, not chrome
- [ ] Hands and counts look correct (the classic AI tell)
- [ ] Audio: no accidental English dialogue under the Urdu voice-over
- [ ] Phone number and rate-page link present in the end card
- [ ] Both aspect ratios exported
